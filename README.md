# Гараж автоэлектрика

Тренажёр для подготовки к работе автоэлектриком.

- `index.html` — игра «Гараж автоэлектрика»: карьера от ученика до своего бокса, 3D-бокс, руки, 25 заказов и 18 уроков: свет, утечка тока, АКБ, стартер и генератор. Сделана под телефон.
- `kurs.html` — учебник: главы 1–2, 3D-лаборатория, домашка.
- `stend.html` — стенд с тремя цепями для тренировки замеров.

Прогресс хранится в браузере на этом устройстве.
